１．はじめに
特許庁は、特許情報の活⽤を促進するためAPI を利⽤した特許情報提供を、令和４年１⽉より開
始しております。本API（以下、「特許情報取得API」といいます。）では、J-PlatPat 及び特許情報
標準データを通じて提供している⽇本国特許庁の特許、意匠及び商標出願情報（実⽤新案出願情
報を除く）及びワン・ポータル・ドシエ（OPD）を通じて提供している五庁（⽇本国特許庁、⽶国特許
商標庁、欧州特許庁、中国国家知識産権局、韓国特許庁）の出願情報について、これら出願情報
の⼀部が取得可能です。
 特許情報取得API による特許情報提供は、安定稼働のためアクセス数に上限を設けております。また、
特許情報取得API の有⽤性や利⽤者ニーズ調査を⽬的とした試⾏段階です。そのため、安定稼働に
関する連絡調整や利⽤者ニーズ調査を円滑に⾏うべく、利⽤にあたっては利⽤者登録が必要となります。

（特許情報取得API に関する情報提供サイト）

https://www.jpo.go.jp/system/laws/sesaku/data/api-provision.html

２．利⽤にあたっての基礎情報
（１）取得可能な情報、アクセス上限及びファイル形式
特許情報取得API は、取得可能な情報により以下の２つに⼤別されます。各API により取得可
能な情報、アクセス数の上限及びファイル形式は、API 情報提供サイト「API ⼀覧」を参照してください。

○国内特許情報取得API︓
J-PlatPat 及び特許情報標準データを通じて提供している⽇本国特許庁の特許、意匠及び商標
出願情報の⼀部（実⽤新案出願情報を除く）
○OPD-API︓
ワン・ポータル・ドシエ（OPD）を通じて提供している五庁（⽇本国特許庁、⽶国特許商標庁、欧
州特許庁、中国国家知識産権局、韓国特許庁）の出願情報の⼀部

（２）情報範囲及び更新頻度
⽇本国特許庁が提供する情報については、以下のとおりです。海外特許庁が提供する情報の種類
や範囲、その更新頻度については、各庁の運⽤によります。

○情報範囲
2003 年7 ⽉以降の特許出願、2000 年1 ⽉以降の意匠・商標出願に関する情報が取得可能
です。また、意匠・商標の書類実体は2019 年1 ⽉以降に受付・作成されたものが取得可能です。
⼀部のAPI ではそれ以前の情報も取得可能ですが、不完全な情報の場合もあります。
○更新頻度
⽇次で更新され、通常、受付・発送などの⼿続が⾏われた⽇の翌⽇に取得可能となります。

（３）利⽤可能時間
特許情報取得API は原則24 時間365 ⽇利⽤可能です。サーバメンテナンス等により利⽤不可
となる場合は、そのスケジュールをAPI 情報提供サイトにてお知らせします。

３．利⽤登録に関する事項
（１）遵守事項
特許情報取得API の利⽤にあたっては、特許庁HP 掲載の利⽤規約への同意とともに、利⽤規
約及び利⽤の⼿引きに記載された事項について遵守する必要があります。

（２）利⽤登録⼿順
利⽤希望者は利⽤登録によりID・パスワードの発⾏を受ける必要があります。
なお、利⽤者が所定数を超過した場合、新規の利⽤登録を終了することもあります。利⽤登録に
関する最新情報は、特許庁HP にて確認してください。

① 利⽤申込書の送付
利⽤希望者は、特許庁HP 掲載の利⽤申込書に必要事項を記⼊した上で、同HP 掲載の特許
庁担当部署へ電⼦メールで送付してください。
② 利⽤者確認
不正登録防⽌のため、特許庁担当部署から利⽤申込書にあるメールアドレス、電話番号への連絡
により利⽤者確認を⾏う場合があります。連絡が取れない場合、利⽤登録不可となります。
③ ID・パスワードの発⾏及び通知
利⽤登録完了後、特許庁担当部署からID・パスワード、アクセストークン取得⽤URL を電⼦メー
ルで通知します。

（３）利⽤申込書に関する留意事項
○利⽤規約への同意
利⽤規約を確認の上、同意できる場合にはチェックボックスにチェックを⼊れてください。同意できない
場合、利⽤登録不可となります。

○メールアドレス及び電話番号
特許庁担当部署と確実に連絡できるメールアドレス及び電話番号を記⼊してください。法⼈の場合
は、担当者を３名まで登録することが可能です。
○利⽤⽬的
利⽤希望者は、可能な範囲で具体的な利⽤⽬的（事業内容等）を記⼊してください。利⽤者が
運営する有料サービスやAI を⽤いた学習等に利⽤することも可能です。
○ID
原則、特許庁担当部署がID を発⾏しますが、以下の条件(a)〜(c)を満たすことで、利⽤希望者
が指定することも可能です。
(a) ①数字、②半⾓アルファベット（⼩⽂字のみ）、③記号（「-（ハイフン）」「_（アンダーバ
ー）「.（ドット）」のうち、2 種以上の⽂字種を含むこと
(b) 8 桁〜15 桁とすること
(c) 個⼈情報を含まないこと
ID の指定にあたっては、「０（ゼロ）」と「O（オー）」など、混同しやすい⽂字は、ルビを付すことなど
により明確化してください。また、利⽤希望者が指定したID が上記条件を満⾜しない場合、特許庁
担当部署がID を指定することもあります。

（４）法⼈名義での利⽤登録
利⽤規約第３条にあるとおり、利⽤者が法⼈であっても、利⽤者に対して複数のID・パスワードを
発⾏しません。なお、親・⼦会社、関連会社、グループ会社等の関係にある場合でも、各法⼈に対し
てID・パスワードの発⾏が可能です。各法⼈で利⽤登録を⾏ってください。

（５）個⼈名義での利⽤登録
個⼈が所属する法⼈の利⽤登録有無によらず、個⼈名義での利⽤登録は可能です。特許情報
取得APIの利⽤が、利⽤者個⼈の私的利⽤（例えば、個⼈名義で⾏う産業財産権に関する研究・
調査分析など）であることを確認した上で、利⽤申込書（個⼈⽤）確認事項のチェックボックスにチェ
ックを⼊れてください。
なお、法⼈の肩書きを利⽤して産業財産権に関する研究・調査分析などを⾏う場合は、私的利⽤
に該当しません。また、利⽤者個⼈の私的利⽤ではなく、所属法⼈等のアクセス上限を増加させる⽬
的等で利⽤した場合は、利⽤者及び関連した法⼈に利⽤制限が課されることがあります。

（６）費⽤負担
特許情報取得API の利⽤に係る通信費等は利⽤者負担となります。

５．アクセスに関する事項
（１）アクセス⽅法
特許情報取得API へアクセスするためには、ID・パスワードによる認証を受け、アクセストークンを取
得する必要があります。具体的なアクセス⽅法は、API 情報提供サイトに掲載しております。

（２）アクセス制限とその解除
特許情報取得API は、安定稼働のためAPI 単位でアクセス数の上限を設けております。アクセス
数のカウントは、ID 単位で午前０時から開始され翌⽇午前０時にリセットします。
アクセス数の上限を超えたリクエストを受けた場合、アクセス制限により回答はエラーとなります。アクセ
ス制限は翌⽇午前０時に解除します。

（３）同⼀ID による複数者の同時アクセス
   特許情報取得API において、同⼀ID を使⽤した複数者の同時アクセスは可能です。ただし、上
記のとおり、アクセス数はID 単位でカウントされます。

６．利⽤登録情報の変更
特許情報取得API の利⽤開始後に、以下の利⽤登録情報に変更が⽣じた場合、利⽤者は速やか
に特許庁HP 掲載の特許庁担当部署へ連絡してください。特許庁担当部署は、利⽤者の本⼈確認の
ため利⽤登録時の利⽤申込書コピー等を求める場合があります。

○メールアドレス及び電話番号
利⽤開始後、利⽤者との連絡が不通になった場合、利⽤登録を解除することがあります。
○ID・パスワード
ID・パスワードの変更は可能です。ただし、利⽤規約第３条にあるとおり、利⽤者に対して複数の
ID・パスワードは発⾏しないため、新ID・パスワードの発⾏に合わせて、旧ID・パスワードは抹消され
ます。また、本⼈確認を⾏った上で、利⽤者にID・パスワードを再通知することも可能です。

なお、利⽤規約第６条に規定する利⽤⽬的内であれば、利⽤開始後に利⽤申込書に記⼊した
利⽤⽬的（事業内容等）以外で利⽤することも可能です。この場合、特許庁担当部署への連絡は
不要です。

７．プライバシーポリシー
特許庁は、特許情報取得API システムから取得した利⽤者のIP アドレス、利⽤したAPI に関する
情報、及び、利⽤登録に関する⼿続きから取得した利⽤者に係る個⼈情報を、特許情報取得API の
円滑な提供や機能改善、今後の特許情報施策の企画・⽴案等の参考情報として利⽤します。
また、特許庁は、法令に基づく開⽰請求があった場合、不正アクセス、脅迫等の違法⾏為があった場
合、その他特別の理由がある場合を除き、収集した情報を上述の利⽤⽬的以外の⽬的のために⾃ら利
⽤することや第三者に提供することはありません。ただし、利⽤者の個⼈情報が特定されないように統計
的に集計処理された情報は、公表されることがあります。
特許庁は、収集した情報の漏えい、滅失⼜はき損の防⽌その他収集した情報の適切な管理のために
必要な措置を講じます。

８．特許情報取得API サポートセンター
 特許情報取得API に関する技術的な質問については、特許情報取得API サポートセンターが対応し
ます。問い合わせは電⼦メールにて、具体的な状況（リクエスト・レスポンス内容等）を記載してください。
なお、利⽤者作成のプログラム等に関する質問には対応できません。また、質問内容により回答には数
⽇を要する場合もあります。
