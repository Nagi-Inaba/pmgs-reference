## ページ4

１．はじめに
特許情報取得API は、J-PlatPat 及び特許情報標準データを通じて提供されている⽇
本国特許庁の特許情報並びにワン・ポータル・ドシエ（以下、「OPD」という。）を通じて提
供されている五⼤特許庁（⽇本国特許庁、⽶国特許商標庁、欧州特許庁、中国国家
知識産権局、韓国特許庁）の審査経過情報の⼀部を、機械的に取得することを可能に
するものです。利⽤者は、当該API を活⽤することにより、特許出願、意匠出願及び商標
出願を通じて提供されている⽇本国特許庁の経過情報並びにOPD を通じて提供されて
いる五⼤特許庁の経過情報を機械的に取得したり、特許庁への⼿続書類作成時の情報
参照・⼊⼒を容易化したりすることができます。
特許情報取得API の活⽤により、特許情報の利活⽤に関する作業負担が軽減され、
また、特許情報の利活⽤の幅が拡⼤することが期待されます。

２．API で提供される情報
（１）API の種類
特許情報取得API で提供される情報は、特許、意匠、商標及びOPD に関する情報
が対象となっており、実⽤新案の情報は、当該API による情報提供の範囲外です。
API は、経過情報をJSON 形式で取得するためのもの、⼿続書類をXML 形式（特
許）やHTM 形式(意匠・商標)で取得するためのものなど、特許は14 種類、意匠及び商
標は各11 種類、OPD は6 種類あります（以下、特許、意匠及び商標に関するAPI を
「国内特許情報取得API」、OPD に関するAPI を「OPD-API」といいます。）。また、API
提供に係るサービスを安定稼働させるため、各API にはアクセス制限が設定されています。
各API の概要と⼀⽇当たりの上限アクセス回数は、表１〜表４に⽰されるとおりです。API
の詳細は、特許情報取得API 仕様書やXML タグ構造仕様書で確認してください。

当該API が参照する情報は、⽇本国特許庁が提供する情報については、⽇次で更新
されています。原則として、特許庁で⼿続が⾏われた⽇の翌⽇、例えば、拒絶理由通知書
であれば同通知書の発送⽇の翌⽇に、API で取得可能になります。

また、⽇本国特許庁以外の五⼤特許庁から提供されている情報の更新時期については、
各庁の運⽤により定められています。

３．利⽤条件
（１）利⽤可能時間
特許情報取得API は、原則として、24 時間365 ⽇利⽤可能です。
ただし、サーバメンテナンス等により、⼀時的に当該API が利⽤できなくなる場合がありま
す。特許庁は、特許情報取得APIの運⽤を⽌める場合、利⽤者にAPI情報提供サイト、
メールで通知します。

＜利⽤登録の⼿順＞
ア．利⽤申込書の作成
国内特許情報取得API（表１〜表３）の利⽤希望者は、別紙１⼜は別紙２の利
⽤申込書の記載欄に、またOPD-API（表４）の利⽤希望者は、別紙３⼜は別紙４の
利⽤申込書の記載欄に所定の事項を記⼊してください。特に注意が必要な事項は、次に
列記するとおりです。
 利⽤規約への同意
利⽤規約に同意した者のみがAPI を利⽤可能です。利⽤希望者は、利⽤規約の全⽂
を読んだ上で、同意できる場合にはチェックボックスにチェックを⼊れてください。
 連絡先
利⽤希望者は、メールアドレスと電話番号を記⼊してください。特許庁からの連絡は、主
に電⼦メールにより⾏われます。連絡先が変更される場合、利⽤者は、速やかに特許庁に
申し出る必要があります。
利⽤開始後、利⽤者と連絡が取れなくなった場合には、利⽤規約８条により、利⽤が
解除される場合があります。
 利⽤⽬的
 特許情報取得API の利⽤⽬的は、利⽤規約６条に記載のとおりです。利⽤希望者は、
可能な範囲で具体的に利⽤⽬的（事業内容等）を記載してください。利⽤者は、申込
書に記載された利⽤⽬的の範囲を超えてAPI を利⽤することになった場合であっても、利
⽤規約に従う限り、利⽤⽬的を変更申請する必要はありません。
 ID
特許庁は、利⽤希望者に対して、ID とパスワードを付与します。ただし、ID は、利⽤希
望者の指定に応じることができます。ID は、次の条件を満⾜する必要があります。
(a)①数字、②半⾓アルファベット（⼩⽂字のみ）、③記号（「-（ハイフン）」「_（アンダ
ーバー）「.（ドット）」のうち、2 種以上の⽂字種を利⽤すること
(b)8 桁〜15 桁とすること
(c)個⼈情報を含まないものとすること
「０（ゼロ）」と「O（オー）」など、混同しやすい⽂字は、ルビを付すことなどにより明確
化してください。

## ページ10

指定されたID が条件を満⾜しない場合、特許情報取得API 担当者は、利⽤希望者
と相談の上でID を決定します。
 担当者（法⼈の場合）
法⼈の担当者は、特許情報取得API 担当者と連絡が可能な者としてください。確実に
連絡できる体制とするために、担当者を３名まで登録することも可能です。担当者ごとに、
メールアドレスと電話番号は１つとします。
なお、担当者のメールアドレスは、担当者個⼈のメールアドレスを登録するものとし、組織
メールやメーリングリストは登録しないでください。
 アクセス上限の変更希望（法⼈の場合）
アクセス上限の変更を求める者は、アクセス上限の変更を求めるAPI と、当該API の上
限変更を求める合理的な事情を記⼊してください。例えば、年間300 件以上の出願⼜は
⼿続代理を実施していることは、合理的な事情として認められます。また、API は、本⼿引
き２．（１）の表１〜表３に記載された番号及びAPI 名称で指定してください（特許
経過情報であれば「１」）。上限を変更することのできるAPI は、原則として、３種類まで
とします。
また、情報提供事業者向けのアクセス上限変更を希望する場合は、特許情報の⼀括ダ
