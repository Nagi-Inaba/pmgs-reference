# PMGS Reference v0.5.1

[English](v0.5.1.en.md)

v0.5.1は、照会時の入力検証と公開前の成果物検査を改善した保守リリースです。

## 修正内容

- 検索・階層・文書取得のページ指定で、小数、bool、SQLiteの整数範囲を超える値を拒否します。明示的な空の`content_types`も不正入力として扱います。
- DBの設置が成功した後、一時ファイル名の削除だけが権限エラーになっても、DB構築の失敗として報告しないよう修正しました。
- 公開policyの`checked_at`に存在しない暦日を指定できないようにしました。
- `validate-public`で、分類・文書JSONの必須項目、値、日付、格納先の分類group、manifestが指すchunkの件数・範囲・ページ・bytes・SHA-256を検査します。
- `audit-public`でA/B両treeを再検証します。過去の正常なreportが残っていても、その後に破損・変更された成果物を合格にしません。
- Workerの文書APIは、未対応schema、必須metadataの欠落、不正な格納先を`503 RELEASE_UNAVAILABLE`として返します。
- Python・Worker・CIの依存関係を更新し、重複テストを統合しました。

## 更新方法

```powershell
uv tool install --force --reinstall "pmgs-reference==0.5.1"
pmgs --version
```

version表示は`pmgs 0.5.1`です。v0.5.0と同じCLI引数、MCPの3 tool、SQLite schema v2を使用するため、この更新のためだけにDBを再構築する必要はありません。型が不正なPython呼出しは修正してください。

公開Web成果物を扱う場合は、新しい`validate-public`と`audit-public`で候補を再検証してください。監査はA/B両treeを再読込するため、その時間も見込んでください。
