# PMGS Reference v0.5.2

[日本語](v0.5.2.md)

v0.5.2 updates the package version and distribution documentation alongside the September 26, 2026 source maintenance release. Python runtime code and dependency requirements are unchanged from v0.5.1.

## Source repository improvements

- Return 404 for an absent classification code within a valid chunk's range. Reject inconsistent manifest totals, chunk counts, boundaries, ordering, releases, and lookup keys with 503.
- Compare weak ETags for conditional GET and HEAD requests, and prevent malformed `If-None-Match` values from producing 304 through partial matches.
- Detect force-added generated artifacts, binary files, links, and machine-specific paths at the repository boundary. Remove an obsolete temporary workflow and an internal operations note.

The Worker and boundary-checking scripts are not included in the wheel or sdist. These changes are available in the [tagged source](https://github.com/Nagi-Inaba/pmgs-reference/tree/v0.5.2). This release does not publish or deploy the Web service.

## Upgrade

```powershell
uv tool install --force --reinstall "pmgs-reference==0.5.2"
pmgs --version
```

The expected output is `pmgs 0.5.2`. CLI arguments, the three MCP tools, and SQLite schema v2 remain compatible with v0.5.1. This update does not require rebuilding the database.
