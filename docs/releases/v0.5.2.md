# PMGS Reference v0.5.2

[English](v0.5.2.en.md)

v0.5.2は、2026年9月26日のソース保守版に合わせて配布案内とversionを更新するリリースです。Pythonの実行コードと依存条件はv0.5.1から変更していません。

## ソースリポジトリの改善

- Workerの分類照会で、正常なchunkの範囲内にある未収録コードを404で返します。manifestの総件数、chunkの件数・境界・順序・release・lookup keyが不整合なら503で拒否します。
- GET・HEADの条件付き取得で弱いETagを比較し、不正な`If-None-Match`の部分一致による304を防ぎます。
- 公開境界検査で、強制追加された生成物、バイナリ、リンク、端末固有pathを検出します。不要な一時workflowと内部運用メモも削除しました。

Workerと境界検査scriptはwheel・sdistに含まれません。これらの修正は[tag付きソース](https://github.com/Nagi-Inaba/pmgs-reference/tree/v0.5.2)に含まれます。Webの公開・deployは行っていません。

## 更新方法

```powershell
uv tool install --force --reinstall "pmgs-reference==0.5.2"
pmgs --version
```

version表示は`pmgs 0.5.2`です。v0.5.1と同じCLI、MCPの3 tool、SQLite schema v2を使用し、この更新のためにDBを再構築する必要はありません。
