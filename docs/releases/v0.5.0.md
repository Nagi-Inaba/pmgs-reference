# PMGS Reference v0.5.0

"
    "公開日: 2026-08-24

"
    "## 概要

"
    "v0.5.0は、v0.4.0以降にmainへ統合した検索、診断、検証、安全性、文書取得の改善を一般利用者へ届けるリリースです。

"
    "## 主な改善

"
    "- 分類・文書検索で重複をまとめてから件数制限し、独立したoffsetとnext_offsetで欠落なく続行できるようにしました。
"
    "- 分類階層の取得をページングし、lookupのN+1照会を除去しました。
"
    "- doctorへタイムアウト、子プロセス回収、3つのMCP toolの実呼出し、SQLite不変性確認を追加しました。
"
    "- CLIのJSON失敗応答を安定したschemaとerror codeへ統一しました。
"
    "- FTS5の索引整合性、virtual table module、列順、UNINDEXED、tokenizerをfail closedで検証します。
"
    "- Codex・Claude Codeの実行ファイル探索から相対PATHと作業ディレクトリ経由の解決を除外しました。
"
    "- release workflowを3 OS、installed wheel、sdist由来wheel、Worker、決定性比較でゲートします。
"
    "- 文書取得のsectionを正のsegment sequence番号へ統一し、locatorを分離しました。
"
    "- 200件を超える文書segmentと関連分類を独立してページングできるようにしました。

"
    "## 互換性上の注意

"
    "Python APIやMCPで文字列をsectionへ渡していた呼出しは、その値をlocatorへ移してください。sectionは1始まりの整数sequence番号です。

"
    "## インストール

"
    "```powershell
"
    "uv tool install --force --reinstall "pmgs-reference==0.5.0"
"
    "pmgs --version
"
    "```

"
    "## 既知の未観測項目

"
    "- Claude Codeの設定と登録は自動検証済みですが、実モデルによるlive MCP評価はnot_observedです。
"
    "- 旧SQLite向けFTS5 fallbackは合成fixtureで検証済みですが、全量JPPMでの時間と一時disk使用量は別Issueで追跡します。
