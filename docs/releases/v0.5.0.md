# PMGS Reference v0.5.0

公開日: 2026-08-24

## 概要

v0.5.0は、v0.4.0以降に`main`へ統合した検索、診断、検証、安全性、文書取得の改善を一般利用者へ届けるリリースです。

## 主な改善

- 分類・文書検索で、重複する本文一致を分類・文書単位へまとめてから件数制限するよう修正しました。
- 分類検索と文書検索に独立した`offset`、`has_more`、`next_offset`を追加し、結果を欠落なく続けて取得できます。
- 分類階層をページング可能なsummary APIへ変更し、結果ごとに完全な`lookup()`を繰り返すN+1照会を除去しました。
- `pmgs doctor`へタイムアウト、停止した子プロセスの回収、3つのMCP toolの実呼出し、SQLite不変性確認を追加しました。
- CLIのJSON失敗応答を、安定したschemaとerror codeを持つ共通envelopeへ統一しました。
- FTS5の転置索引、virtual-table module、列順、`UNINDEXED`指定、tokenizerをfail closedで検証します。
- Codex・Claude Codeの実行ファイル探索から、相対`PATH`、空の`PATH`要素、作業ディレクトリ経由の解決を除外しました。
- release workflowをLinux、Windows、macOS、installed wheel、sdist由来wheel、Worker、決定性比較でゲートします。
- 文書取得の`section`を、1始まりのsegment sequence番号へ統一し、文字列selectorを`locator`へ分離しました。
- 200件を超える文書segmentと関連分類を、独立したlimit／offsetで最後まで取得できるようにしました。
- `section`とoffsetへSQLite signed 64-bit整数範囲外の値が渡された場合、`OverflowError`を漏らさず構造化エラーとして拒否します。

## 互換性上の注意

v0.4.0でPython APIまたはMCPの`section`へ文字列のlocatorやheadingを渡していた呼出しは、その値を`locator`へ移してください。v0.5.0の`section`は正の整数sequence番号だけを受け付けます。

```python
# v0.4.0まで
store.get_document(document_id, section="page:1")

# v0.5.0
store.get_document(document_id, locator="page:1")
store.get_document(document_id, section=201)
```

## インストールと更新

新規インストール:

```powershell
uv tool install pmgs-reference
```

v0.4.0から確実に更新する場合:

```powershell
uv tool install --force --reinstall "pmgs-reference==0.5.0"
pmgs --version
```

期待するversion表示:

```text
pmgs 0.5.0
```

## 既知の未観測項目

- Claude Codeの設定、登録、skill導入は自動検証済みですが、実モデルによるlive MCP評価は`not_observed`です。
- 旧SQLite向けFTS5 fallbackは合成fixtureで検証済みですが、全量JPPMでの所要時間と一時disk使用量はIssue #56で追跡します。

## 配布境界

wheelとsdistには、SQLiteを構築・検索するPythonコード、CLI、読み取り専用MCP、AI向けskillだけを含めます。PMGS原本、展開後の原資料、生成したSQLite、全量export、認証情報は含めません。
