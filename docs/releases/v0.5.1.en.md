# PMGS Reference v0.5.1

[日本語](v0.5.1.md)

v0.5.1 is a maintenance release that improves query input checks and validation of public artifacts.

## Fixes

- Reject fractional values, booleans, and values outside SQLite's integer range in pagination parameters. Reject an explicitly empty `content_types` list.
- Preserve a successful database installation when removing its temporary filename fails with a permission error.
- Reject impossible calendar dates in publication-policy `checked_at` values.
- Validate classification and document JSON fields, values, dates, storage groups, and manifest references against actual chunk counts, ranges, pages, bytes, and SHA-256.
- Revalidate both A/B trees during `audit-public`, so old successful reports cannot conceal subsequently changed artifacts.
- Return `503 RELEASE_UNAVAILABLE` from the document API for unsupported schemas, missing metadata, and invalid chunk locations.
- Update Python, Worker, and CI dependencies and consolidate redundant tests.

## Upgrade

```powershell
uv tool install --force --reinstall "pmgs-reference==0.5.1"
pmgs --version
```

The expected output is `pmgs 0.5.1`. CLI arguments, the three MCP tools, and SQLite schema v2 remain compatible with v0.5.0. This update alone does not require rebuilding the database. Correct Python calls that supplied invalid parameter types.

Revalidate public Web candidates with the new `validate-public` and `audit-public`. Allow time for the audit to read both A/B trees again.
