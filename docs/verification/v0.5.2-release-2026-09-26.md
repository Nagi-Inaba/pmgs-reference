## ローカル候補

署名が有効なWindows CPython 3.14.3を使用し、既存仮想環境の参照先を照合した。

| 検査 | 結果 |
| --- | --- |
| lock整合、tag/version照合、公開境界 | 合格。220候補 |
| Ruff lint / format、mypy | 合格。32 source module |
| 全体pytest | 354 passed / 10 skipped / 1 failed。失敗は導入ガイドに旧versionが残っていた文書契約 |
| 導入ガイド修正後のproject契約 | 14 passed。日英README・ガイド、構造化契約、Markdownリンクを含む |
| wheel・sdist構築と配布物metadata/hash検査 | 合格。version 0.5.2の2 file |
| 隔離wheel導入 | `ready` → `already_ready`、doctor成功、FI検索`exact`、stdio MCP 3 tool、`pmgs 0.5.2` |
| sdist由来wheel | 元wheelのruntime・metadataと一致し、隔離導入にも合格 |

10 skipはWindowsのsymlink権限9件とPOSIX専用条件1件による。重点pytestはWindows native `access violation`診断を出したが、14件合格・終了code 0で完了した。全体pytestにはこの診断はなかった。診断を試験成功と混同せず、原因未特定のローカル残余事項として記録する。

Workerにはこのversion更新による変更がないため、直前のLinux検証73件・WebMCP 3件とmain CIを参照する。tag workflowでも再検証する。
