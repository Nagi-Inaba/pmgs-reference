## 契約ごとの証拠

| 契約 | 検証 |
|---|---|
| PythonとWorkerの正規化一致 | 共有`schemas/normalization-vectors.json`をworkerdで全件照合 |
| 分類照会は最大2 R2 read | FI、Fターム、IPC現行版、IPC旧版、大容量group fixtureで`Server-Timing`を確認 |
| 文書照会は最大2 R2 read | manifestのpage・sequence indexから対象chunkだけを取得 |
| 入力境界 | scheme、code、language、edition、release、重複・未知query、path traversalを400または404へ固定 |
| 不整合のfail closed | 欠損chunkを503 `RELEASE_UNAVAILABLE`へ固定 |
| HTTP配信 | HTML、Markdown negotiation、ETag 304、HEAD、CORS、preflight、cache、security headerを確認 |
| WebMCP非必須 | 未対応時は無変更、対応時はread-only toolを1件だけ登録、API・network errorを安全なtool結果へ変換 |
